Important

  • Do not rename this repository or the GitHub account. All NFC tags and printed QR codes contain hardcoded URLs. After a rename, anyone could claim the old username and publish content under these URLs.
  • Do not edit pages here. All pages, including this one, are generated from one configuration. To change a page: change the configuration, regenerate the pages, upload the generated files, then verify the published site. A page edited by hand no longer matches the generated version and fails the integrity check.
  • Do not use git push from a local machine. Change files only through the GitHub web interface ("Add file" → "Upload files" for generated pages, "Delete file" for retired pages) to prevent email leakage in commit metadata.
  • Keep two-factor authentication enabled on this account.
  • Do not add real names, personal email addresses, or other identifying information to any file in this repository.
